# Minecraft GUI library

A simple GUI library for Minecraft plugins.
For installation instructions and usage examples, visit [docs](https://xagui.xap3y.eu)

## Supported versions & platforms

- 1.8 - 26.2
- Spigot, Paper, Purpur, Folia
